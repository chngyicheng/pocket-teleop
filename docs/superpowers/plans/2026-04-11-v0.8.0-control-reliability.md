## Task 1 — Keyboard: immediate twist on key-up

**Files:** `web-client/src/keyboard_handler.ts`, `web-client/test/keyboard_handler.test.ts`

**Problem:** `boundKeyUp` only removes key from `keysDown`. Next poll (up to 200ms) sends the updated values. Robot coasts for up to 200ms after key release.

**Fix:** Re-compute and fire twist immediately in `boundKeyUp`.

- [ ] **Step 1: Update `boundKeyUp` in `keyboard_handler.ts`**

Replace the existing `boundKeyUp` assignment inside the constructor:

```typescript
    this.boundKeyUp = (e: KeyboardEvent) => {
      this.keysDown.delete(e.key);
      // Fire immediately — don't wait for next poll interval.
      // Ensures zero velocity is published the moment the last key is released.
      if (this.enabled) {
        const v  = this.velocity;
        const lx = this.keysDown.has('w') ? v : this.keysDown.has('s') ? -v : 0;
        const az = this.keysDown.has('a') ? v : this.keysDown.has('d') ? -v : 0;
        const ly = this.keysDown.has('ArrowRight') ? v : this.keysDown.has('ArrowLeft') ? -v : 0;
        this.onTwistCb(lx, ly, az);
      }
    };
```

- [ ] **Step 2: Add tests to `keyboard_handler.test.ts`**

Add inside the existing `describe('KeyboardHandler', ...)` block:

```typescript
  it('fires zero twist immediately on last key-up (no poll wait)', () => {
    const twists: [number, number, number][] = [];
    const kh = new KeyboardHandler({ onTwist: (lx, ly, az) => twists.push([lx, ly, az]) });
    kh.start();
    document.dispatchEvent(new KeyboardEvent('keydown', { key: 'w' }));
    twists.length = 0; // clear poll-driven entries
    document.dispatchEvent(new KeyboardEvent('keyup', { key: 'w' }));
    expect(twists).toHaveLength(1);
    expect(twists[0]).toEqual([0, 0, 0]);
    kh.stop();
  });

  it('fires updated twist on key-up mid-combo (e.g. w+d, release w)', () => {
    const twists: [number, number, number][] = [];
    const kh = new KeyboardHandler({ velocity: 1, onTwist: (lx, ly, az) => twists.push([lx, ly, az]) });
    kh.start();
    document.dispatchEvent(new KeyboardEvent('keydown', { key: 'w' }));
    document.dispatchEvent(new KeyboardEvent('keydown', { key: 'd' }));
    twists.length = 0;
    document.dispatchEvent(new KeyboardEvent('keyup', { key: 'w' }));
    // w released, d still held: lx=0, az=-1
    expect(twists).toHaveLength(1);
    expect(twists[0]).toEqual([0, 0, -1]);
    kh.stop();
  });

  it('does not fire on key-up when disabled', () => {
    const twists: [number, number, number][] = [];
    const kh = new KeyboardHandler({ onTwist: (lx, ly, az) => twists.push([lx, ly, az]) });
    kh.start();
    kh.setEnabled(false);
    document.dispatchEvent(new KeyboardEvent('keydown', { key: 'w' }));
    twists.length = 0;
    document.dispatchEvent(new KeyboardEvent('keyup', { key: 'w' }));
    expect(twists).toHaveLength(0);
    kh.stop();
  });
```

```javascript
// ── E-stop ────────────────────────────────────────────────────────────────────
const estopBtn = document.getElementById('estop-btn');

function triggerEstop() {
  client.sendTwist(0, 0, 0);
  estopBtn.style.outline = '3px solid #fff';
  setTimeout(() => { estopBtn.style.outline = ''; }, 300);
}

estopBtn.addEventListener('click', triggerEstop);

document.addEventListener('keydown', (e) => {
  if (e.key !== ' ') return;
  // Skip when typing in an input field
  const tag = (document.activeElement?.tagName ?? '').toLowerCase();
  if (tag === 'input' || tag === 'textarea' || tag === 'select') return;
  e.preventDefault();
  triggerEstop();
});
```

## Task 3 — Gamepad calibration: require "Ready" before sampling

**Files:** `web-client/index.html`

**Problem:** `startCalStep()` immediately starts a `setInterval` that collects 5 axis samples at 200ms each. By the time the user reads the instruction and moves the stick, sampling may already be complete with at-rest values.

**Fix:** Split `startCalStep` into two phases:
1. **Prompt phase** — show instruction, show "I'm holding it — Ready" button, hide Skip.
2. **Sample phase** — starts when user clicks Ready; collects 5 samples at 200ms; commits.

The existing `calNextBtn` element can serve as the "Ready" button.

- [ ] **Step 1: Update calibration HTML label** (if needed)

Find `<button id="cal-next">` and set its initial text to "Ready — holding stick".

- [ ] **Step 2: Rewrite `startCalStep` and wire `calNextBtn`**

Replace the existing `startCalStep` function and its `calNextBtn` logic:

```javascript
    function startCalStep() {
      calInstruction.innerHTML = CAL_STEPS[calStepIndex].instruction + '<br><small style="color:var(--text-muted)">Hold the stick in position, then click Ready.</small>';
      calStartBtn.style.display = 'none';
      calNextBtn.style.display  = 'inline';
      calNextBtn.textContent    = 'Ready — holding stick';
      calSkipBtn.style.display  = 'inline';
      calSamples = [];
      // Sampling begins only when user clicks Ready (see calNextBtn handler below).
    }

    function beginSampling() {
      calNextBtn.style.display = 'none';
      calSkipBtn.style.display = 'inline';
      calInstruction.innerHTML = CAL_STEPS[calStepIndex].instruction + '<br><small style="color:var(--text-muted)">Sampling… keep holding.</small>';
      calSamples = [];
      calSampleInterval = setInterval(() => {
        const gp = Array.from(navigator.getGamepads()).find((g) => g !== null) ?? null;
        if (!gp) return;
        calSamples.push([...gp.axes]);
        if (calSamples.length >= 5) {
          clearInterval(calSampleInterval);
          calSampleInterval = null;
          commitCalStep();
        }
      }, 200);
    }

    calNextBtn.addEventListener('click', beginSampling);
```

Remove or update any existing `calNextBtn.addEventListener` that conflicts.
