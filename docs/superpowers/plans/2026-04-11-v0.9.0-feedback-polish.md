## Task 1 — RTSP URL validation

**Files:** `web-client/src/video_source.ts`, `web-client/test/video_source.test.ts`

**Problem:** `apply('rtsp', '')` sends empty source to MediaMTX. UI has a partial guard (empty check) but no URL format check.

**Fix:** Add `validate(mode, rtspUrl): string | null` to `VideoSourcePicker`. Returns error string or `null` if valid. `apply()` calls it and returns early.

- [ ] **Step 1: Add `validate` to `VideoSourcePicker` in `video_source.ts`**

Add after the `save` method:

```typescript
  /**
   * Validate mode + rtspUrl before applying.
   * Returns null if valid, or a human-readable error string.
   */
  validate(mode: VideoSourceMode, rtspUrl: string): string | null {
    if (mode === 'rtsp') {
      if (!rtspUrl.trim()) return 'RTSP URL is required.';
      if (!rtspUrl.trim().startsWith('rtsp://')) return 'RTSP URL must start with rtsp://';
    }
    return null;
  }
```

- [ ] **Step 2: Call `validate` inside `apply`**

Update `apply()` — add before `const body = buildMtxSource(...)`:

```typescript
  async apply(mode: VideoSourceMode, rtspUrl = ''): Promise<string> {
    const err = this.validate(mode, rtspUrl);
    if (err) return `validation-error:${err}`;
    const body = buildMtxSource(mode, rtspUrl);
    // ... rest unchanged
```

## Task 2 — Stream health indicator

**Files:** `web-client/src/whep_client.ts`, `web-client/test/whep_client.test.ts`, `web-client/index.html`

**Problem:** `WhepClient` only exposes `onStream`, `onError`, `onClose`. Operator can't tell if video is connecting, live, or retrying without watching the video element.

**Fix:** Add `onStateChange?: (state: WhepState) => void` callback. Fire at every state transition.

States:
- `'connecting'` — initial; also set when retry starts
- `'live'` — stream received and playing
- `'retrying'` — connection closed; back-off timer running
- `'error'` — unrecoverable error (distinct from retry)

- [ ] **Step 1: Add `WhepState` type and `onStateChange` to `whep_client.ts`**

Add type export before the `WhepCallbacks` interface:

```typescript
export type WhepState = 'connecting' | 'live' | 'retrying' | 'error';
```

Add to `WhepCallbacks`:

```typescript
export interface WhepCallbacks {
  onStream: (stream: MediaStream) => void;
  onError:  (msg: string) => void;
  onClose:  () => void;
  onStateChange?: (state: WhepState) => void;  // optional
}
```

- [ ] **Step 2: Fire `onStateChange` at transitions inside `WhepClient`**

Find the relevant points in the `WhepClient` implementation and add `this.callbacks.onStateChange?.(state)` calls:

| Where | State to emit |
|---|---|
| Start of `connect()` (begin attempt) | `'connecting'` |
| `onStream` callback line (stream received) | `'live'` |
| `onClose` / connection-dropped branch | `'retrying'` |
| `onError` callback line | `'error'` |
| Start of retry (before scheduling retry timer) | `'retrying'` |

## Task 3 — Latency display

**Files:** `web-client/src/teleop_client.ts`, `web-client/index.html`

**Problem:** `TeleopClient` fires `onPong()` but doesn't measure roundtrip time. No latency info displayed.

**Fix:** Track when ping was sent. On pong, compute RTT = `Date.now() - pingSentAt`. Expose via `onLatency?: (ms: number) => void`.

**Note:** Keepalive sends ping only when no twist was sent in the last 200ms. During active driving (twist every 200ms), no pings fire → no latency updates. This is acceptable: latency display updates when idle, which is the most useful time to see it.

- [ ] **Step 1: Add `pingSentAt` tracking and `onLatency` to `teleop_client.ts`**

Add to `TeleopClientOptions`:

```typescript
  onLatency?: (ms: number) => void;
```

Add private field to `TeleopClient`:

```typescript
  private pingSentAt = 0;
```

Update `startKeepalive` — record time when ping is sent:

```typescript
    this.keepaliveId = setInterval(() => {
      if (Date.now() - this.lastSentAt >= 200) {
        this.pingSentAt = Date.now();
        this.connection.send(buildPing());
        this.lastSentAt = Date.now();
      }
    }, this.keepaliveIntervalMs);
```

Update `handleMessage` — compute RTT on pong:

```typescript
    } else if (msg.type === 'pong') {
      if (this.pingSentAt > 0) {
        this.options.onLatency?.(Date.now() - this.pingSentAt);
        this.pingSentAt = 0;
      }
      this.options.onPong?.();
    }
```
